================================================================================
 ROTEIRO DE CRIAÇÃO DOS NPCs DE QUEST
 Sistema de Quests — DiamanteAzul UO
================================================================================

COMO USAR
---------
1. Entre no jogo com uma conta GameMaster (ou superior).
2. Vá até o local onde o NPC deve ficar.
3. Cole cada linha deste arquivo no chat, UMA POR VEZ, na ordem.
   Cada [addquestnpc pede um clique no chão; cada [questnpcset pede um
   clique no NPC recém-criado.

POR QUE O "npcid" É OBRIGATÓRIO
-------------------------------
Os JSON em Data/Quests identificam os NPCs por um ID estável
("npc_capita_maelis", "npc_enfermeira_sera"...). O serial do NPC muda a cada
respawn e o nome de exibição pode ser editado, então sem o npcid:

  - os objetivos "Fale com..." nunca recebem progresso;
  - a entrega da quest não é reconhecida;
  - as cartas lacradas (grantItems) nunca são entregues.

Definir o npcid com [questnpcset npcid <id> marca o NPC como giver e
ASSOCIA AUTOMATICAMENTE todas as quests cujo giverId/turnInId seja esse id —
não é mais preciso usar [questnpcaddquest uma a uma.

ATENÇÃO — ORDEM
---------------
Rode [questreload ANTES de definir os npcid, para que o repositório já tenha
as quests carregadas e a associação automática funcione.

    [questreload

 VERIFICAÇÃO FINAL
================================================================================

[questreload
[questlist
[questdiag

Detalhe de uma quest específica:
[questinfo quest_fortaleza_conhecendo

use [questreset depois para devolver o jogador ao estado normal):

================================================================================
 COMANDOS DISPONÍVEIS
================================================================================

 [questreload                 recarrega os JSON de Data/Quests
 [questlist                   lista ids/nomes/estado de todas as quests
 [questinfo <id>              detalha uma quest (objetivos, pré-requisitos)
 [questdiag                   diagnóstico completo: o que está impossível e por quê
 [criarquest                  cria uma quest nova pelo gump
 [editarquest                 edita uma quest já existente pelo gump
 [addquestnpc <nome>          cria um QuestNPC no local clicado
 [questnpcset npcid <id>      vincula o NPC ao id usado nos JSON (auto-associa quests)
 [questnpcset bio <texto>     biografia do NPC
 [questnpcset location <txt>  descrição do local
 [questnpcset range <n>       alcance de interação
 [questnpcset speechhue <n>   cor da fala
 [questnpcaddquest <id>       associa uma quest manualmente (valida o id)
 [questnpctalk                força o início da conversa com o NPC clicado
 [queststart <id>             inicia a quest para o jogador-alvo (GM)
 [questcomplete <id>          completa à força (GM)
 [questfail <id>              falha à força (GM)
 [questprogress <id>          mostra o progresso do jogador-alvo (GM)
 [questreset <id>             zera o histórico do jogador-alvo (Admin)
 [questgive <id>              dá a quest ignorando pré-requisitos (GM)
 [missoes / [quests           abre o rastreador de quests (jogador)
